# 歡迎閱讀 <br/>OSPO Book

這本書為組織提供一套關於開放原始碼的知識基礎，協助規劃如何在專業的 Open Source Program Office（OSPO）團隊協助下，使用、貢獻及建立開放原始碼專案。內容幫助讀者更清楚理解 OSPO 在組織中的角色，並彙整一群具有深厚開放原始碼策略、社群與管理經驗的貢獻者 [^1] 共同在公開環境下製作的資源。主軸包含：如何訂定政策、流程與策略，妥善使用、貢獻與建立對組織產品或服務至關重要的開放原始碼專案，以及如何維持日常營運。

* 為什麼組織需要，或可能不需要 OSPO。
* 如何評估組織是否已具備引進 OSPO 的準備。
* OSPO 在不同類型組織中扮演的角色。
* 常見棘手情境與建議做法。
* 日常營運的實務建議，從制定開放原始碼政策到與外部開放原始碼社群有效互動。
