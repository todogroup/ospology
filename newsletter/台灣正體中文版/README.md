## 如何貢獻 OSPO 電子報

透過 [LF Newsletter Platform](https://todogroup.org/community/osponews/) 發送的
OSPO 電子報內容由 OSPO 社群共同製作，並以此儲存庫中的 `yyyy-mm-dd.md`
檔案維護。若要開始貢獻，只要編輯 `yyyy-mm-dd.md` 檔案中的任一段落，
再開啟 PR 即可。

可貢獻的電子報內容包括：

* 在「🧳 OSPO 職缺」新增開放原始碼或 OSPO 相關職缺
* 在「🚀 徵稿與研討會」新增即將舉行的開放原始碼活動
* 在「📌 若錯過了」分享開放原始碼管理與 OSPO 相關的精彩文章、部落格文章或研究
* 在「🙋 OSPO 討論」新增 OSPO Forum 上的討論

接著，ospology 維護者會審查並合併內容。

如需進一步了解，請參閱 [OSPO 電子報準則](newsletter-guidelines.md)。
