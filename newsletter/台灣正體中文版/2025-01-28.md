## 📌 若錯過了：產業新聞與文章

這裡整理最近與 OSPO 相關的重要內容與資源：

- Microsoft OSPO 制定一套框架，用來說明開源風險與投資策略，協助團隊以結構化方式理解並爭取開源專案的資源。[說明在這裡](https://github.com/microsoft/OSPO/blob/main/learning_resources/using-oss/investment-framework.md)
- Hitachi 成立 Open Source Program Office，負責帶領集團在全球策略性採用開源軟體，並加入 TODO Group。[公告在這裡](https://todogroup.org/blog/todo-member-hitachi/)
- Intersect OSPO 公佈自己的 Roadmap，說明如何在 Cardano 生態系中強化開源治理與社群參與，同時也加入 TODO Group。[公告在這裡](https://todogroup.org/blog/todo-member-intersect/)
- Alliander OSPO 開發 OSPO Code Scanner，一套 GitHub Actions 工作流程，協助在程式碼開源之前，自動檢查是否符合開源最佳實務。[專案在這裡](https://github.com/Alliander-opensource/ospo-code-scanner)
- 荷蘭員工保險局的 OSPO 將主辦下一屆 OSPOlogyLive Amsterdam，時間是 2025 年 3 月 26 日（三）至 3 月 27 日（四），聚焦永續、資金與新法規對開源風險管理與 SBOM 採用的影響。[活動資訊在這裡](https://community.linuxfoundation.org/events/details/lfhq-ospology-european-chapter-presents-ospologylive-amsterdam/)
- 中國 OSPOlogy chapter 年度報告指出，ZTE、Vivo、Ant Group、Bytedance 等企業的 OSPO 在多場聚會中分享開源管理最佳實務，並推廣在中國組織採用 OSPO。[報告討論在這裡](https://github.com/todogroup/ospology/discussions/547)
- OSPOlogy Local Chapter Japan 分享最新進度，包括整理詳細的 OSPO Local Meetup 記錄，以及編寫 OSPO Easy FAQ，針對建立與經營 OSPO 的常見問題提供說明，協助日本組織建立 OSPO。[相關內容在這裡](https://github.com/todogroup/ospology/discussions/538)
