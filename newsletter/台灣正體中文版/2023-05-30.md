# OSPO 電子報第 23 期

## ✨ 每月公告

**讓 OSPO 聲音被聽見，[一起參與 2023 OSPO Survey](https://www.research.net/r/SD6K27F)：** TODO Group 與 LF Research 在 Alibaba Group、CHAOSS、Cybertrust、Dynatrace、GitHub、InnerSource Commons Foundation、開源社、OpenInfra Foundation、Open Source Initiative（OSI）、OpenChain Project、OpenSSF 與 Salesforce 等夥伴支援下，正在進行 2023 年 OSPO 調查。今年問卷特別加入永續與安全相關問題。

**歡迎[一起完善 Open Source Program Office（OSPO）定義](https://github.com/todogroup/ospodefinition.org/pull/9)：** 邀請所有參與開源專案與基金會的人，以及 OSPO 實務社群，一同協作，打造更具包容性的 OSPO 定義，能忠實反映組織採用開源的最新趨勢。

## 📺 下一場 OSPOlogy 社群電話會議

這裡是一個讓大家分享經驗、和不同領域 OSPO 導師交流的空間！

**Lessons Learned from Ant Group OSPO：** 當螞蟻集團從零開始建立 OSPO 時，很快就發現，企業想推動開源會更加不容易，因為整體成本與風險都更高，也需要更長時間才能累積動能。

在這場座談裡，講者會從一篇文章（<https://doi.ieeecomputersociety.org/10.1109/MC.2022.3219638>）出發，深入探討螞蟻集團這間中國科技公司在管理 Open Source Program 時的最佳實務，並整理實作過程中各種角色與挑戰。報名連結：https://community.linuxfoundation.org/events/details/lfhq-todo-group-ospology-presents-lessons-learned-from-ant-group-ospo/

> 想持續追蹤 OSPOlogy 活動嗎？歡迎[訂閱 OSPOlogy Chapter](https://community.linuxfoundation.org/todo-group/)，就不會錯過任何一場會議！
