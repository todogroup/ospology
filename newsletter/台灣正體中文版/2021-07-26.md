# OSPO 電子報第 1 期

嗨 👋 歡迎收看 #OSPONews，這是每月一次、掌握 Open Source Program Office（OSPO）動態與趨勢的電子報。

## 📢 準備好迎接 OSPOCon！

這是一場專為想要經營成功開源專案與計畫的實務工作者設計的活動，大家可以在現場交流經驗、學彼此的做法。

第一屆 [OSPOCon](https://events.linuxfoundation.org/ospocon/) 將在美國華盛頓州西雅圖登場，別錯過！

## 🚀 Academic OSPO 的誕生

Open@RIT 的使命，是在校園裡推動「全校一起開放」的文化，讓教職員與學生可以透過開源協作驅動創新。

想了解 RIT 如何建立自己的 Open Source Program Office：
https://www.linux.com/featured/openrit-the-birth-of-an-academic-ospo/

## 📺 OSPOlogy：TODO 社群線上討論

這個系列是讓不同產業的 OSPO 實務者彼此分享、互相交流的空間。

別錯過接下來的社群電話會議，可以在這裡報名：
https://community.linuxfoundation.org/todo-group/
