# OSPO 電子報：2022 年 2 月

## 📝 TODO Work Days

TODO Work Days 主要是一起清理 TODO Group GitHub 組織裡的各種 issue，例如：

- 持續進行中的工作小組任務
- TODO Guides 內容
- 新版 TODO 網站的內容
- 蒐集並整理新的 OSPO 職務說明
- 撰寫 OSPONews 內容

等等。
Work Days 對所有人開放，只要訂閱 TODO 社群郵件論壇，就能收到會議邀請。[詳細資訊請見](https://github.com/todogroup/work-day-activities#work-day-activity-tracker)。

* EMEA & APAC：3 月 14 日（週一），10:00 UTC
