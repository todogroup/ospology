### 參加 OSPO 專家帶領的小組討論、分享與圓桌交流

OSPOlogyLive Germany 會聚集在開放原始碼領域活躍的不同利害關係人，包括產業領袖、開放原始碼專案維護者與政策制定者，一起用一整天的時間參與由專家主導的深度座談、簡報，以及圓桌／工作坊活動。
大家會一起討論德國與更廣泛歐洲地區的組織，在開放原始碼相關議題上遇到的最新趨勢與挑戰。主要主題包括：

* 開放原始碼安全與風險緩解
* InnerSource 與組織文化
* 專案健康與社群永續
* 組織層面的開放原始碼實務
* 對外開源與策略

[點此報名這場聚焦且名額有限的活動](https://community.linuxfoundation.org/events/details/lfhq-ospology-european-chapter-presents-ospologylive-germany/)。更多活動資訊與議程請見官網。

### 認識 OSPO Glossary

OSPO Glossary 專案託管於 <https://ospoglossary.todogroup.org/>，目標是提供談論 Open Source Program Office（OSPO）時常用術語的參考基準。
若想參與貢獻，請參考專案網站上的[貢獻指南](https://ospoglossary.todogroup.org/contribute/)。

<img src="https://github.com/todogroup/ospology/assets/43671777/c85b2a05-f86c-40c3-a897-e4cd78682ef3" width="650" height="350" />

### 一起參與 OSPO Book Project

OSPO book project 是 OSPOlogy repo 底下較新的計畫之一。
不論是撰寫新章節、協助審閱既有 PR、在 `glossary.md` 裡補充新術語，或是把內容翻譯成自己的母語，都很歡迎加入成為社群的一份子。
[可以先閱讀這篇公告開始](https://todogroup.org/blog/ospo-book-project/)。
