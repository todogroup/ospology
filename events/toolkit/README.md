# OSPOlogy reusable toolkit

These ten files reproduce the supplied `01-Reusable-Toolkit` materials without content changes. Select the materials needed for each edition and replace their placeholders. Form templates are question outlines, not deployed forms.

The sponsorship guide adds guidance for standalone events and events organized within Linux Foundation conferences.

| Task | Supplied material |
| --- | --- |
| Plan the event | [Event brief](01-Planning/OSPOlogy-Event-Brief-Template.md) |
| Build the programme | [Agenda CSV](02-Programme/OSPOlogy-Agenda-Template.csv) |
| Collect attendee interest | [Attendee interest form](03-Forms/OSPOlogy-Attendee-Interest-Form-Template.md) |
| Collect session proposals | [Speaker and session submission form](03-Forms/OSPOlogy-Speaker-and-Session-Submission-Form-Template.md) |
| Gather feedback | [Feedback form](03-Forms/OSPOlogy-Feedback-Form-Template.md) |
| Prepare speakers | [Speaker checklist](04-Speaker-Assets/OSPOlogy-Speaker-Checklist-Template.md) |
| Invite participants | [Invitation email](05-Communications/OSPOlogy-Invitation-Email-Template.md) |
| Promote the event | [Social post](05-Communications/OSPOlogy-Social-Post-Template.md) |
| Capture discussions | [Roundtable notes](06-Onsite/OSPOlogy-Roundtable-Notes-Template.md) |
| Share outcomes | [Event recap](07-Follow-Up/OSPOlogy-Event-Recap-Template.md) |
| Coordinate sponsorship | [Sponsorship guide](08-Sponsorship/OSPOlogy-Sponsorship-Guide.md) |

Use with the [OSPOlogy framework](../framework.md). Publication and attribution arrangements must match the session rules.
